# Michi

**Большая цель. Следующий шаг.**

Michi — не трекер привычек и не система ежедневных галочек. Это персональный навигатор по долгосрочным целям.

Главная задача приложения — не заставить пользователя сесть за учёбу, а вовремя заметить, что он слишком долго занимается одним удобным направлением и почти не двигает другие важные цели.

## Основная логика

Michi совмещает две карты:

- **карта внимания** — куда реально ушло учебное время за последние недели;
- **карта знаний** — какие инструменты уже освоены, какие ещё изучаются и что логично брать следующим.

Из их сочетания приложение отвечает на вопрос: **«Куда мне разумнее двигаться сейчас?»**

Никаких streak-механик, штрафов за пропуск, обязательного ежедневного плана и накопления просроченных задач.

## Сбережения

Финансовая цель: **¥2 400 000** на горизонте примерно 6–8 лет.

Модуль хранит реальные поступления и реальные суммы, которые пользователь решил отложить. Получил 1000 ₽ и отложил 0 ₽ — это допустимая запись, а не «провал недели».

## AI

Архитектура остаётся независимой от провайдера:

`Michi UI → AI Service → GigaChat | OpenAI | другие провайдеры`

Первым планируется GigaChat. AI должен объяснять ошибки, создавать мини-тесты и помогать выбирать следующий шаг, но приложение должно оставаться полезным и без AI.

## Локальный запуск

1. Установить Node.js 22+.
2. Выполнить `npm install`.
3. Скопировать `.env.example` в `.env.local`.
4. Выполнить `npm run dev`.

Публикуемый Supabase key не является серверным секретом. Ключи AI-провайдеров должны храниться только на серверной стороне.
