# Michi

**Большая цель. Следующий шаг.**

Michi — персональное учебное приложение, которое превращает долгосрочные цели в месячные этапы и небольшие ежедневные задания.

## MVP

- долгосрочные цели по японскому, профильной математике и русскому;
- адаптивные планы «минимум / норма / усиленный день»;
- темы и слабые места;
- календарь настроения с причинами;
- базовая статистика;
- архитектура для GigaChat сейчас и OpenAI API позже;
- PWA для установки на телефон.

## Стек

- React + TypeScript + Vite
- Supabase Auth + Postgres + RLS
- GitHub Pages
- Supabase Edge Functions для AI-слоя на следующем этапе

## Локальный запуск

1. Установить Node.js 22+.
2. Выполнить `npm install`.
3. Скопировать `.env.example` в `.env.local`.
4. Выполнить `npm run dev`.

Публикуемый Supabase key не является серверным секретом. Любые ключи GigaChat/OpenAI будут храниться только на серверной стороне.
